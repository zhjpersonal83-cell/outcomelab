# OutcomeLab

Break it. Teach it. Measure it.

An interactive lab for discovering when an AI classifier gets things wrong, teaching it corrections, and checking whether those corrections help on examples it has not seen.

[Live demo](https://outcomelab.zhongjiehuang.com) · [GitHub](https://github.com/zhjpersonal83-cell/outcomelab)

## What you can do

- Try your own examples and challenge the model's predictions.
- Teach corrections and compare the results before and after learning.
- Check performance on ordinary and deliberately more difficult examples.
- Undo a change and return to the exact earlier model state.
- Export results to review or share later.

Each experiment has its own temporary workspace. Corrections and experiment text are not kept as a permanent personal training history.

## A simple way to explore

Start with an example, inspect the prediction, add a correction, and compare the evaluation results. Use rollback to see which changes made a difference.

## Scope

A personal research and software demonstration developed with AI assistance. The evaluation uses synthetic examples; its results do not establish real-world safety or suitability for high-stakes decisions. No improvement is claimed unless the measured results support it.
