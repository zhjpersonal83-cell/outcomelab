OPEN THE BLACK BOX

Small model.
Inspectable behaviour.

4096 hashed text features → linear classifier → three support queues. Java implements the original one-vs-rest logistic SGD updates using the preserved trained baseline. No LLM or simulated training.

54 training, 18 validation and 36 test examples use separate templates. Validation is reserved; no tuning is performed. The test set shares vocabulary with training and is intentionally easy. Repeatedly viewing scores can bias your choices: these are exploratory demo metrics, not independent research results.

Each browser load creates an in-memory sandbox. Sessions expire after 30 minutes of inactivity or a server restart. No accounts, trackers or shared feedback model. MySQL stores only the verified baseline; corrections remain in memory. Exports contain the text you entered.

Personal, non-commercial portfolio and learning demonstration. No claims of production readiness. Architecture, tests, limitations and deployment instructions accompany the source.
