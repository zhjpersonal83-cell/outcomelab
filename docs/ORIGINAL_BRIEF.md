## Product
Build **OutcomeLab — Break It. Teach It. Measure It.**, a compelling, English-first interactive AI reliability laboratory that recruiters can understand in 60 seconds. This is a NEW product, not a rename, fork, or deployment of Marginloom or IAFM. Do not copy proprietary source. Its primary value proposition: visitors try to break a classifier, correct errors, trigger distribution shift, observe genuine before/after learning and robust held-out evaluation. Provide a no-login public demo using synthetic/non-sensitive data, with a guided 60-second challenge, transparent model details, live prediction confidence, correction feedback, drift experiments, calibration, confusion matrix, performance metrics, model versioning and rollback. Distinguish simulation from actual computation; never fake performance gains, benchmark numbers, or training events. Feedback must not poison a global shared model; use isolated per-session training sandboxes and rate limiting. A simple real online learner (e.g., scikit-learn SGDClassifier partial_fit with TF-IDF or HashingVectorizer) is preferable to a fake LLM learning loop. Document its limitations. Include a second challenge demonstrating adversarial prompt-injection defenses only if implemented safely and clearly.
